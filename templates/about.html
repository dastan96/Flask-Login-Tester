About Flask Login Tester

Project Overview

Flask Login Tester is a lightweight QA engineering lab demonstrating secure Flask authentication, automated testing, CI execution, and live test-result reporting.

What This Project Demonstrates

  • Flask authentication demo
  • pytest API testing
  • Web Routes testing
  • Playwright login UI automation
  • GitHub Actions CI
  • Automated report generation
  • Live QA dashboard

Current Test Coverage

The automated suite covers the Login API, Web Routes, and Playwright login UI checks.

CI And Reporting Flow

GitHub Actions runs pytest and generates JUnit XML plus a pytest HTML report. Raw CI artifacts are retained for 14 days, while sanitized latest.json and index.html files are published through GitHub Pages.

Dashboard Data Flow

Flask fetches latest.json server-side, exposes the sanitized internal contract through GET /api/test-results/latest, and the dashboard consumes that Flask endpoint. GitHub Pages remains the public reporting source.
