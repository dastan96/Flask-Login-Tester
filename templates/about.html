Flask Login Tester - Full Project Summary

📌 Project Overview

Flask Login Tester is a Flask-based web application designed to:

  • Provide secure user authentication.
  • Automate API testing using pytest.
  • Store test results dynamically in an SQLite database.
  • Display real-time test results on a visually appealing dashboard.
  • Automate test execution using GitHub Actions every Sunday at midnight.

📂 Project Architecture

FlaskProject/
├── .github/workflows/        # GitHub Actions CI/CD Workflow
│   ├── run-tests.yml         # Automated test execution workflow
│
├── instance/                 # SQLite Database Storage
│   ├── test_results.db       # Stores test execution results
│
├── reports/                  # Stores pytest-generated JSON reports
│   ├── report.json
│
├── static/                   # Frontend Static Assets
│   ├── js/
│   │   ├── dashboard.js      # Fetches and visualizes test data
│   ├── css/
│   │   ├── styles.css        # Custom styles
│
├── templates/                # HTML Pages (Login, Welcome, About)
│   ├── login.html
│   ├── welcome.html
│   ├── about.html
│
├── tests/                    # Automated Test Scripts
│   ├── api/
│   │   ├── api_tests.py      # Pytest API test cases
│   ├── report.html           # HTML report of test results
│   ├── results.json          # Test execution summary
│
├── util/                     # Utility Functions
│   ├── utils.py              # Saves test results into SQLite
│
├── app.py                    # Flask Application
├── run_all_tests.py          # Runs all tests & updates DB
├── requirements.txt          # Python dependencies
├── README.md                 # Project documentation

🔥 How Everything Works Together

  1. Users log in via login.html (Flask authentication).
  2. API tests execute (pytest runs via run_all_tests.py).
  3. Results are extracted (report.json → SQLite DB).
  4. Dashboard (welcome.html) displays real-time results using dashboard.js.
  5. GitHub Actions triggers automated test execution weekly (CI/CD pipeline).
